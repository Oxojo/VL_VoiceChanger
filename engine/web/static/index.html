マイクでストリーミング変換 試験機能

下の変換設定を使って、話しながら変換音声を再生します。ヘッドホンを使用してください。

LLVCは自動選択ではCPUを使います。GPUがCPUより遅い場合があります。LLVCはStreamVCとは別方式です。RVCモデル・ピッチ・話者・hop設定は使いません。Voice Mixingは未対応です。

モデル配布元から取得します。初回はダウンロードが必要です。ヘッドホンを使用してください。

モデルの状態を確認中…

hop 500 / context 150 / crossfade 50 ms。現在の設定を基準に比較できます。

モデルを選んで開始してください

既定設定では 700 ms の入力蓄積に加え、推論・通信・再生に時間がかかります。

入力 → 再生開始予定の推定遅延: 出力待ち

音声グラフ上の推定で、実マイクから耳までの遅延は未測定です。モデル準備・マイク許可待ちは含みません。行には内数や異なる時計の計測が含まれるため、すべてを足し合わせないでください。

開始すると計測します。

区間の設定・使い方

変換モードを「分割」にすると hop / context / crossfade を調整できます。マイク変換はモードの選択にかかわらずストリーミングで処理します。

ノイズ除去とハム除去は 0 にしてください。処理が追いつかないときは停止します。1 回 180 秒までで、再開できます。

マイクは localhost または HTTPS で利用できます。変換中はこの画面を開いておいてください。
