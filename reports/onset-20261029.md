# 発音の立ち上がりを保つ修正

## 相談と確認範囲

変換結果の発音開始が「ふんわりする」との相談を受けて確認。
提供された `output.wav` は 40 kHz・モノラル・3.18 秒、ピーク 0.741、
静音部の推定フロアは -60.7 dBFS。音声そのものは Git 管理外。
元の録音と変換設定は未提供のため、この録音での原因特定・聴感改善の判定は未実施。

## 変更

1. RMVPE が 0 Hz と判定した無声区間を、合成器に渡す前に有声 F0 で埋めない。
   合成器の SineGen は F0 > 0 を有声判定に使うため、全補間すると子音・息・休止にも
   周期音源が使われてしまっていた。ピッチシフト後も 0 Hz を保持する。
2. ノイズ除去マスクの追従係数を、上昇時 0.9・下降時 0.35 とした。
   以前は両方向 0.35 であり、短い音の立ち上がりも遅く開いていた。

## 自動確認

- 全 57 テスト成功。無声区間の保存（ピッチシフト含む）、全無声、短い音の立ち上がりの回帰テストを追加。
- 人声の代用となる合成試験: 16 kHz、定常ノイズ振幅 0.01 に 1 kHz・0.2 秒のトーンを追加、除去強度 0.7。
  - 先頭 20 ms の RMS / 安定部 RMS: 旧処理 0.712 → 新処理 0.979。
  - 静音部フロア: 入力 -40.5 dBFS → 旧 -55.2 / 新 -51.5 dBFS。
  - この試験では立ち上がり保存と引き換えに残留ノイズが増えるが、入力比では約 11 dB 低減。
  - この数値は合成信号の試験結果であり、子音の聴取評価ではない。
- 手元の既存日本語 TTS 入力（7.63 秒）を CUDA で変換して完走。
  - F0 追従 0.999、エネルギー包絡相関 0.961、クリップなし。
  - 出力 `logs/verify/onset-fix-ja.wav`（Git 管理外）。

## 次の試聴

サーバーを再起動し、同じ入力・モデル・ピッチ・モードで再変換する。
まずノイズ除去を 0 にして比較し、必要なら弱い除去設定を追加する。
入力にすでに「ノイズ除去を試す」を適用済みなら、元の録音を読み直して比較する。
差が不十分な場合は、元の録音とモデル・ピッチ・ノイズ除去強度・一括／分割の設定を確認する。
既存の変換結果に増幅や EQ をかけても、失われた子音情報を復元できるとは限らない。
