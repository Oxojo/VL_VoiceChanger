# 当日の運用と操作手順

実証実験（Phase 2 / Phase 3）とリハーサルで使う手順。**操作担当がこの 1 枚だけで再現できる**ことを目標にする。

---

## 0. 役割

| 役割 | 人数 | 担当すること |
| :--- | :--- | :--- |
| 実装・設定担当 | 1 名 | 起動、設定、トラブル対応 |
| 演者 | 1 名 | 通常発話・早口・感情発話を試す |
| 試聴・評価担当 | 1〜2 名 | 変換音の明瞭さ・キャラクター性を判定 |

兼務は可能。ただし **変換音を演者以外が聴く** ことを推奨（遅延した自分の声は話しづらい）。

## 1. 開始前チェックリスト（10 分）

| # | 確認項目 | 済 |
| :-- | :--- | :--- |
| 1 | PC の電源プランが省電力になっていない | [ ] |
| 2 | ブラウザのタブ・ゲーム・配信ソフトを閉じた | [ ] |
| 3 | マイク・オーディオ IF・ヘッドホンが接続されている | [ ] |
| 4 | Windows の既定入出力が想定どおり | [ ] |
| 5 | オーディオ IF のダイレクトモニターが **OFF**（二重に聞こえる場合） | [ ] |
| 6 | ヘッドホンの音量が過大でない | [ ] |
| 7 | 使用モデルとプロファイルが一致している | [ ] |

> 二重に聞こえる場合の切り分け: オーディオ IF のダイレクトモニター音量つまみを 0 にする → それで消えればダイレクトモニターが原因。

## 2. 起動

```powershell
.\scripts\Start-VoiceChanger.ps1 -Profile character-a
```

初回のみ、モデルを登録する（2 回目以降は「登録済み」と表示されて終了する）。

```powershell
.\scripts\Register-Model.ps1 models/tsukuyomi/tsukuyomi-normal1.pth -Name 'つくよみちゃん（通常1）'
```

プロファイルのうち **REST API で変更できる値**（モデル/スロット、AUDIO 方式、GPU、ノイズゲート、EXTRA）は
スクリプトで反映できる。まず `-DryRun` で差分を確認する。

```powershell
.\scripts\Set-VoiceProfile.ps1 character-a -DryRun
.\scripts\Set-VoiceProfile.ps1 character-a
```

表示されたチェックリストのとおり GUI を設定する。

1. モデルを選択する
2. AUDIO 方式・input・output を確認する
3. TUNE / INDEX / F0 Det / CHUNK / EXTRA / S. Thresh を合わせる
4. **start** を押す

> **TUNE（pitch）/ INDEX / F0 Det / CHUNK はスクリプトで変更できない。**
> `PUT /api/slot-manager/slots/{index}` はボディを受け付けず再読込のみのため、これらは GUI で設定する。
>
> **start は GUI で押す。** REST の `operation/start` だけでは変換スレッドが起動しない（実測）。

## 3. 発話前の最終確認

| 確認 | 見方 | 目標 |
| :--- | :--- | :--- |
| 変換遅延 | `buf` と `res` の表示 | **buf > res** になっている |
| 入力レベル | 発話時にメーターが振れる | 大声でも振り切れない |
| 無音時のノイズ | 発話していないとき | 変換音が漏れていない |
| 音量 | 変換後の声 | ヘッドホンで聴いて過大・過小でない |
| 声質 | 通常発話 | 明瞭でキャラクターに合う |

`buf < res` のときは音切れの原因になる。詳細は [06-tuning.md](06-tuning.md)。

## 4. 運用中の監視

- 変換が止まっていないか、**目視と聴取の両方**で確認する（自動計測だけでは音切れは分からない）
- 長時間の場合は `Test-Stability.ps1` を併走させ、事象をキー入力で記録する

```powershell
.\scripts\Test-Stability.ps1 -Profile character-a
```

| キー | 記録される事象 |
| :--- | :--- |
| `D` | 音切れ |
| `S` | 変換停止・フリーズ |
| `N` | 声の崩れ |
| `M` | 自由記述メモ |
| `Q` | 途中終了 |

### 4.1 変換音の証跡を残す（録音）

聴取評価だけでは「実際に変換されていたか」を後から示せない。**server モード**では録音機能が使える。

1. **録音**（録音開始）を押す
2. 評価用の固定文を発話する（例:「こんにちは。これは音声変換のテストです。」）
3. もう一度 **録音** を押す（録音停止）→ GUI が zip をダウンロードする
4. `vcClient.root` に残る `input.wav`（変換前）と `output.wav`（変換後）を `logs/verify/` へコピーする

| 項目 | 実測値（2026-10-28） |
| :--- | :--- |
| 形式 | 44.1 kHz / 32 bit float / モノラル |
| ファイル名 | `vcClient.root\input.wav` / `output.wav`（録音のたびに**上書き**） |
| 長さ | 録音開始〜停止の実時間 |
| 注意 | **client モードでは録音できない**（GUI の録音は server モード専用） |

## 5. モデル／設定の切り替え（Phase 4）

追加目標。**無瞬断は必須としない。発話の切れ目で切り替える。**

1. 演者に「切り替えます」と伝え、発話を止めてもらう
2. GUI でモデルを切り替える（または別プロファイルの値を適用する）
3. 新しいモデルの読み込み完了（キャラクター画像の表示）を待つ
4. 短く発話して声質を確認する
5. 必要なら **start を押し直す**

切り替え中は音が出ない。**本番中に切り替える場合は台本上で発話が途切れる箇所を決めておく。**

## 6. 停止

1. **stop** を押す（いきなりウィンドウを閉じない）
2. GUI のタブを閉じる
3. コンソール（黒い画面）で `Ctrl + C`、またはウィンドウを閉じる
4. 変換が残っていないことを確認する

## 7. 終了後の記録

| 記録項目 | 記録先 |
| :--- | :--- |
| 使用したプロファイルと設定値 | `config/profiles/*.json` |
| 発生した不具合と対処 | [03-troubleshooting.md](03-troubleshooting.md) の記録欄 |
| 聴取評価 | [04-verification.md](04-verification.md) の評価シート |
| 自動計測の結果 | `reports/stability-*.md` |

**「うまくいった」だけで終わらせない。** 数値（CHUNK, EXTRA, buf, res, TUNE）を残さないと、次回・他部員が再現できない。
