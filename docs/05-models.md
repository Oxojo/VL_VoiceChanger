# モデル選定と利用規約の記録

企画書 4 章に対応。**初期検証ではモデル 1 種類に限定する。**

> 「無料だから自由にマージ・再配布できる」とは判断しない。
> 採用時に **利用規約 URL・必要なクレジット・禁止用途・部内共有や改変の条件** を記録する。

## 1. 選定基準

| 基準 | 内容 | 必須 |
| :--- | :--- | :-- |
| 形式 | RVC の `.pth`（＋任意で `.index`） | 必須 |
| ライセンス | 本企画の用途（サークル内での実演・検証）が許容される | 必須 |
| クレジット | 必要表記が明示されている | 必須 |
| 禁止用途 | ライブでの利用が禁止されていない | 必須 |
| 入手性 | 無償で入手でき、取得元が明確 | 必須 |
| 品質 | 通常発話・早口・感情発話で破綻しにくい | 推奨 |

## 2. 候補の比較

| 候補 | 提供元 | 形式 | 規約 URL | クレジット | ライブ利用 | 判定 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| つくよみちゃん 公式 RVC モデル | 夢前黎 / つくよみちゃん公式サイト | RVC | https://tyc.rei-yumesaki.net/work/software/rvc/terms/ | **変換元の声＋モデルの2つ**が必要 | **可**（ボイスチェンジャー用途を明示的に許容） | 第1候補 |
| あみたろ 公式 RVC モデル | あみたろの声素材工房 | RVC | https://amitaro.net/voice/voice_rule/ | クレジット必須 | **可**（AIボイチェン用途を明示） | 第2候補 |

**採用**: つくよみちゃん公式RVCモデル（ver 1.0.0 / 2023.06.16 / 取得 2026-10-28）

理由:

- ボイスチェンジャー用途（VTuber 活動・他キャラクターへの声当て）が規約で**明示的に許容**されている
- 5 種類のモデル（通常1〜3・強・弱）が同梱され、演者の声質に合わせて選べる
- 無償・登録不要で取得でき、取得元 URL が安定している
- 再配布の条件が明文化されている（後述）


> zip 内のファイル名は日本語だが、**ASCII 名にリネームして配置している**（VC Client / RVC はパスに非 ASCII が入ると失敗することがあるため）。連番との対応は上表のとおり。

| 項目 | 方針 |
| :--- | :--- |
| 配置 | `models/<character>/`（**Git 管理外**） |
| 共有方法 | 部内の共有ドライブ等。**公開リポジトリに置かない** |
| 同一性の担保 | 上表の SHA-256 を配布時に照合する |
| バックアップ | モデルは再入手できない場合があるため複数箇所に保管 |
| index ファイル | **本モデルには同梱されていない**（`.pth` のみ）。index 無しでも動作するが、声質の再現度は index ありより下がる |
| 規約の証跡 | `README-tyc.txt` / `LICENSE-tyc-terms.txt` をモデルと同じフォルダに置く |

```bash
# ハッシュの取得（モデルフォルダ内の .pth をすべて）
python -c "import hashlib, pathlib; [print(p.name, hashlib.sha256(p.read_bytes()).hexdigest()) for p in sorted(pathlib.Path('models/tsukuyomi').glob('*.pth'))]"
```

### 5.1 VC Client への登録状態（2026-10-28 実測）

| `slot_index`（API） | GUI 表示 | モデル名 | `inferencer_type` | サンプルレート | embedder | pitch estimator |
| ---: | :--- | :--- | :--- | ---: | :--- | :--- |
| 5 | **6.** | つくよみちゃん（通常1） | `pyTorchRVCv2` | 40000 Hz | `hubert_base_l12` | `rmvpe_onnx` |
| 6 | **7.** | つくよみちゃん（通常2） | `pyTorchRVCv2` | 40000 Hz | `hubert_base_l12` | `rmvpe_onnx` |

- 実体は `vcClient.root\model_dir\<slot_index>\`（`params.json` + `.pth`）。**GUI の番号は 0 始まりの API 値 + 1。**
- 登録は `python -m vlvc register-model`（REST API）。**52.7 MB で 0.3 秒**。`inferencer_type` / `sample_rate` / `embedder` は `.pth` から自動判定される。
- 空きスロットは自動選択される。番号を固定したいときは `--slot` を指定する。
- 不要になったスロットは削除できる（`model_dir\<index>` も消える）。

```bash
# 登録（初回・追加とも同じ）
python -m vlvc register-model models/tsukuyomi/tsukuyomi-normal1.pth --name 'つくよみちゃん（通常1）'

# 番号を指定して登録
python -m vlvc register-model models/tsukuyomi/tsukuyomi-normal3.pth --name 'つくよみちゃん（通常3）' --slot 7

# スロットの削除（例: slot 7）
curl -X DELETE http://localhost:18000/api/slot-manager/slots/7
```

> **`slot_index` は 0 始まり。** 削除後に番号が詰められることはない。
> Windows の PowerShell では `curl` が別名のため `curl.exe` を使う。
