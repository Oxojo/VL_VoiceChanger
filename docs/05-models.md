# モデル選定と利用規約の記録

企画書 4 章に対応。**初期検証ではモデル 1 種類に限定する。**

> 「無料だから自由にマージ・再配布できる」とは判断しない。
> 採用時に **利用規約 URL・必要なクレジット・禁止用途・部内共有や改変の条件** を記録する。

---

## 1. 選定基準

| 基準 | 内容 | 必須 |
| :--- | :--- | :-- |
| 形式 | RVC の `.pth`（＋任意で `.index`） | 必須 |
| ライセンス | 本企画の用途（サークル内での実演・検証）が許容される | 必須 |
| クレジット | 必要表記が明示されている | 必須 |
| 禁止用途 | ライブでの利用が禁止されていない | 必須 |
| 入手性 | 無償で入手でき、取得元が明確 | 必須 |
| 品質 | 通常発話・早口・感情発話で破綻しにくい | 推奨 |

## 3. 規約の記録シート（採用モデルごとに 1 枚）

```markdown
### モデル名:

- ファイル名:
- 提供元:
- 取得元 URL:
- 取得日:
- バージョン / 更新日:
- SHA-256:
- 規約 URL:
- 規約の確認日:
- 必要なクレジット表記:
- 禁止用途:
- 商用利用:
- 改変（マージ・再学習）:
- 再配布:
- 部内共有の可否:
- 声質変換しての利用:
- 判断に迷った点と確認方法:
```

### 記入例（つくよみちゃん）

以下は VC Client 公式 README に転載されている条件の要約。**採用時は必ず一次情報（規約 URL）を確認する。**

| 項目 | 内容 |
| :--- | :--- |
| クレジット | 「つくよみちゃんコーパス（CV.夢前黎）」© Rei Yumesaki |
| 禁止 | 人を批判・攻撃すること（定義はつくよみちゃんキャラクターライセンスに準じる） |
| 禁止 | 特定の政治的立場・宗教・思想への賛同または反対を呼びかけること |
| 禁止 | 刺激の強い表現をゾーニングなしで公開すること |
| 禁止 | 他者に対して二次利用（素材としての利用）を許可する形で公開すること |
| 許容 | 鑑賞用の作品としての配布・販売 |

### 記入例（あみたろ）

| 項目 | 内容 |
| :--- | :--- |
| 許容 | 声素材・コーパス読み上げ音声から音声モデルを作ること、自分の声をあみたろの声に変換して使うこと |
| **必須** | **あみたろ（小春音アミ）の声に声質変換していることを明記し、本人が話しているわけではないと誰でも分かるようにする** |
| 制約 | 発話内容は声素材の利用規約の範囲内。センシティブな発言をしない |

> ライブで使用する場合、**MC や配布物に「声質変換を使用している」旨を明記する運用**が必要になる。表記場所（開演前のアナウンス、プログラム、配信概要欄など）を事前に決める。

## 4. モデルファイルの管理

| 項目 | 方針 |
| :--- | :--- |
| 配置 | `models/<character>/`（**Git 管理外**） |
| 共有方法 | 部内の共有ドライブ等。**公開リポジトリに置かない** |
| 同一性の担保 | SHA-256 を規約シートに記録し、配布時に照合する |
| バックアップ | モデルは再入手できない場合があるため複数箇所に保管 |
| index ファイル | 任意。規約上も別扱いになる場合があるため取得元を記録する |

```powershell
# ハッシュの取得
Get-FileHash -Algorithm SHA256 .\models\character-a\character-a.pth | Format-List
```

## 5. モデルマージの扱い（追加検討）

企画書 4.3 のとおり、**単体モデルで目標を満たせない場合のみ**検討する。

前提条件:

- [ ] 使用する VC Client のバージョンで Merge Lab が使える
- [ ] **素材側**の規約がマージを許容している
- [ ] **モデル側**の規約がマージを許容している
- [ ] 生成モデルの取り扱い（再配布・公開の可否）が決まっている
- [ ] 生成モデルのクレジット表記方法が決まっている

**初期検証では必須としない。** 条件を 1 つでも満たせない場合は実施しない。
