# モデル選定と利用規約の記録

企画書 4 章に対応。**初期検証ではモデル 1 種類に限定する。**

> 「無料だから自由にマージ・再配布できる」とは判断しない。
> 採用時に **利用規約 URL・必要なクレジット・禁止用途・部内共有や改変の条件** を記録する。

---

## 1. 選定基準

| 基準 | 内容 | 必須 |
| :--- | :--- | :-- |
| 形式 | RVC の `.pth`（＋任意で `.index`） | 必須 |
| ライセンス | 本企画の用途（サークル内での実演・検証）が許容される | 必須 |
| クレジット | 必要表記が明示されている | 必須 |
| 禁止用途 | ライブでの利用が禁止されていない | 必須 |
| 入手性 | 無償で入手でき、取得元が明確 | 必須 |
| 品質 | 通常発話・早口・感情発話で破綻しにくい | 推奨 |

### 参考：つくよみちゃん公式RVCモデル

2026-10-28 に規約ページ（最終更新 2026-10-07）を確認した内容の要約。**採用時は必ず原文を読む。**

| 項目 | 内容 |
| :--- | :--- |
| 利用範囲 | 個人・法人、営利・非営利を問わず概ね利用可。**収益の有無で可否が変わるのは「再配布」だけ**で、収益額に上限はない |
| ボイスチェンジャー用途 | 「自分の声をつくよみちゃんの声に変換する」「動画やライブ配信等でボイスチェンジャーとして使う（VTuber活動、他キャラクターへの声当て等）」が明示されている |
| **クレジット** | **「変換元の音声」と「つくよみちゃん公式RVCモデル」の両方**の表記が義務。RVC を悪用していないことを示すための規定 |
| 禁止 | 特定の政治的立場・宗教・思想への賛同/反対を呼びかける活動への利用 |
| 禁止 | 実在する人物・団体・商品等を批判・攻撃する活動への利用、およびそうした活動をしている名義での利用 |
| 禁止 | 他者の権利を侵害すること |
| 禁止 | 本モデルで作成したコンテンツを、他者に二次利用を許可する形で公開すること（例外あり） |
| 表現 | 刺激の強い表現を含む場合は注意書き・ゾーニングを行う |
| 自分以外の声からの変換 | **変換元の音声側の利用規約も確認する**必要がある |
| マージ | 「他の話者の声質とマージする」項目が設けられている（条件は原文参照） |

**本企画への影響**

- 演者本人の声を変換するので、「変換元の音声」のクレジットは **演者名（またはサークル名）** になる。ライブでどう表記するかを決める必要がある → 下の「クレジット運用」を埋める。
- 演者が**他人の声**（既存音源など）を変換元にする場合は、その音源の規約確認が別途必要。**初期検証では演者本人の生声のみを使う。**

### 参考：あみたろの声素材工房

2026-10-28 に規約ページ（最終更新 2026-10-23）を確認した内容の要約。**採用時は必ず原文を読む。**

| 項目 | 内容 |
| :--- | :--- |
| 利用範囲 | クレジット（名前）を書けば**無料・商用可**。子供でも企業でも利用可 |
| RVC モデル | 「AIボイスチェンジャー・テキスト読み上げ」用途として公開されている |
| 明示的に可 | 声当て（オリジナルキャラ・ゲームキャラの声として使う）、切り貼り・加工・ピッチ変換、AI の学習 |
| 禁止 | お子さんに安心して見せられない使い方（年齢制限作品・ゾーニングなしの刺激の強い表現） |
| 禁止 | 政治活動・宗教活動への利用 |
| 禁止 | 声素材の転売・独占 |
| 禁止 | 人を傷つける・差別する・だます・悪用する行為 |
| 条件 | 他のソフトやサービスを通じて使う場合は、**そのソフトの規約も守る**（VC Client 側の条件も確認） |
| 英語版 | 日本語版と英語版で内容が少し異なる。日本語を理解できる場合は日本語版が適用される |

**本企画への影響**

- 「クレジットを書く」が必須。表記例はサイト内に用意されているため、**採用時に実際の文言をコピーして記録する（要確認）**。
- 「AIボイチェンで自分の声をあみたろの声に変換して使う」ことは VC Client 公式 README でも案内されているが、**あみたろ本人が話しているわけではないと分かる表記**が求められる運用になる。

## 4. クレジット運用（ライブでどう出すか）

ライブでは「クレジットを書く」だけでは足りない。**どこに、いつ、どう出すか**を決めておく。

| 出す場所 | 記載内容 | 担当 | 済 |
| :--- | :--- | :--- | :-- |
| 開演前アナウンス | 例:「本公演では音声変換を使用しています。声は演者本人です。」 |  | [ ] |
| 配布プログラム / 概要欄 | モデル名・権利者・規約 URL |  | [ ] |
| スクリーン / 映像 | エンドロール等 |  | [ ] |
| 配信アーカイブ | 概要欄に固定 |  | [ ] |

> 「変換している」ことを隠さない方が、規約上も安全で、炎上リスクも下がる。**演者本人が話していることを明示する**のが基本。

## 5. モデルファイルの管理

| 項目 | 方針 |
| :--- | :--- |
| 配置 | `models/<character>/`（**Git 管理外**） |
| 共有方法 | 部内の共有ドライブ等。**公開リポジトリに置かない** |
| 同一性の担保 | SHA-256 を規約シートに記録し、配布時に照合する |
| バックアップ | モデルは再入手できない場合があるため複数箇所に保管 |
| index ファイル | 任意。規約上も別扱いになる場合があるため取得元を記録する |

```powershell
# ハッシュの取得
Get-FileHash -Algorithm SHA256 .\models\character-a\character-a.pth | Format-List
```

## 6. モデルマージの扱い（追加検討）

企画書 4.3 のとおり、**単体モデルで目標を満たせない場合のみ**検討する。

前提条件:

- [ ] 使用する VC Client のバージョンで Merge Lab が使える
- [ ] **素材側**の規約がマージを許容している
- [ ] **モデル側**の規約がマージを許容している
- [ ] 生成モデルの取り扱い（再配布・公開の可否）が決まっている
- [ ] 生成モデルのクレジット表記方法が決まっている

**初期検証では必須としない。** 条件を 1 つでも満たせない場合は実施しない。
